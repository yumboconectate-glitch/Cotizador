🧾 Facturación electrónica (CRM)

Cuando apruebes una orden con IVA, el cotizador enviará automáticamente los datos de la factura (cliente, ítems, base, IVA, total) a esta URL — apúntala a tu n8n o CRM para generar la factura electrónica en tu sistema (WispHub, Siigo, etc.).

Servidor de correo (SMTP)

Desde aquí configuras el correo con el que el sistema envía cotizaciones y notificaciones. Cualquier empresa puede poner su propio servidor.

Puerto 465 usa SSL directo; 587 usa STARTTLS. La contraseña se guarda en el servidor y nunca se muestra de vuelta.
